# NutriRun (Godot 4.5)

This folder contains the **NutriRun** Godot project.

## Run

- **Godot Editor**: open `project.godot`, press **F5**
- **CLI**:

```bash
godot --path /Users/fritzzzz/DevGigs/games/nutrirun
```

- **Validate project loads**:

```bash
godot --path /Users/fritzzzz/DevGigs/games/nutrirun --check-only
```
